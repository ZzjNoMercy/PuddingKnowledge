# Installed Knowledge identity observation

`python -m knowledge_platform.distribution.installed_identity` inspects a noneditable installed `puddingknowledge-local` distribution and emits the versioned `puddingknowledge-installed-identity/v1` receipt. It checks the owned package inventory and size/SHA256 against RECORD, including package resources and METADATA/WHEEL. Missing, added, changed, linked or special owned files reject. The loaded identity module must belong to that installation. Receipts contain a deterministic inventory digest, version and count, without host paths.

This is local consistency evidence, not a signature or an authenticated release assertion (`authenticated=false`). The first observation requires a trusted selected installation or an external trusted pin. Recording it detects subsequent same-version changes; it cannot establish initial provenance. Generated bytecode, third-party dependencies, stdlib, startup hooks and arbitrary hostile same-user/interpreter behavior are outside this fingerprint. It does not lock an installation against concurrent replacement or prove atomic execution of a code snapshot. Registered `.pyc` entries are rejected; the current no-compile uv installation is supported.

A consumer must persist the complete receipt before migration and compare a fresh receipt after the delegated operation, before completion publication. Changed or missing receipts must reject old-plan replay without modifying the previous completed checkpoint. This module grants no writer authority and does not implement CUTOVER or thaw.
