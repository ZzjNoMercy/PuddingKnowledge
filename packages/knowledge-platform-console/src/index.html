Knowledge Platform Console

通过 Platform 公共 REST 契约发现知识并查询；结果中的 Evidence 使用 portable knowledge:// URI。

Platform 管理

记录 Collection 的只读 freshness 观测。写入只包含公开身份、状态和 revision，不接受文件路径或凭据。

QueryResult 元数据

只读取 QueryResult 的状态和结果摘要，不下载 artifact 正文。

Analytics / Database Query

两阶段只读查询：先生成服务端 QueryPlan，再由同一 Space 的调用者显式执行；不接受用户输入 SQL。

Schema 只读取当前 Space 中 Database Collection binding 允许的表和列；内部兼容字段仍使用 dataset_id。不显示连接信息、文件路径、凭据或 SQL。

MCP Resources

通过固定 MCP Resource contract 发现和读取可访问的 portable Resource。

Semantic Assets

只读查看当前 Space 的 Semantic Markdown 状态；未挂载 registry 时明确显示能力不可用。

Sources / Connectors

只读查看 Connector 的逻辑身份和同步状态；Source Item 不展示外部 token、URL、路径或原始 metadata。

Host-managed Authorization

这里只查看授权状态或创建待授权意图；宿主/Vault 执行真正授权。本 Console 不接收 token、授权 URL 或凭据引用。

Bitable 实时操作

仅操作当前授权 Source 的 Schema、范围和实时行查询。行数据只返回当前调用者，不保存到 Platform；空范围会明确拒绝全部表。

Upload / Package Import

Admin staging 边界：只提交宿主预先登记的 binding ID 和内容摘要，不提交文件路径、凭据或原始内容；成功后仍需后续 Processing/Index 流程才能激活。

Index Candidate

只提交 Collection/provider 的固定逻辑身份；source binding 由宿主配置，候选完成后不会自动激活。

Platform 通知

只读取已明确绑定到当前 Space 的 Platform 事件；收件箱已读状态不复制、不复用旧通知 ORM。

Asset Binding Review Queue

只读查看本地候选绑定的 review ID 和 Catalog 摘要。人工批准仍须在宿主命令行显式执行；Console 不批准、不写 Catalog、不展示本地路径。

Processing Job 状态

只读取本地 Catalog 的任务生命周期摘要，不显示文件路径、租约或原始错误。
